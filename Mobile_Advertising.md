## 1. FreshBite Mobile Marketing Case Study
FreshBite: healthy meals, protein-rich food, salads/bowls, office lunch subscriptions, 30-min delivery.

**Target audience:** Urban, age 22–35, corporate/tech professionals, fitness-conscious, frequent online-food-orderers, heavy mobile users.

**Mobile consumer journey:**
- **Awareness** — mobile ads, social, influencers, events
- **Consideration** — app/website exploration, reviews
- **Order** — 30-min delivery, subscriptions
- **Experience** — convenience, freshness, easy ordering
- **Retention** — push notifications, subscription/promo offers

**2.1 Banner Ads** — small rectangular ads (image + copy + CTA e.g. "Buy Now"). Strong for visibility/traffic, average for interaction.

**2.2 Interstitial Ads** — full-screen takeovers. High visibility, lower interaction (users can skip/close). Best for launches/major campaigns.

**2.3 Video Ads** — for awareness/storytelling; communicates more than a static banner.
Types: In-stream, Out-stream, In-feed, Video banner, Social video, Interactive video, 360°.

**In-Stream vs Out-Stream:**
| In-Stream | Out-Stream |
|---|---|
| Plays inside existing video (YouTube pre-roll, OTT) | Plays outside a video player (mid-article) |
| User already watching video | User browsing/reading |
| Stronger video-viewing intent | Extends video reach |

**Video placement:** Pre-Roll (before) → Mid-Roll (during) → Post-Roll (after — limited use, since many users don't finish the video).

**3. Playable Ads** — interactive, mostly mobile gaming; lets users try a demo before downloading. High engagement + app acquisition.

**4. Rewarded Ads** — user gets a reward for completing an action (e.g. Google Pay rewards, scratch cards). Drives active participation.

**5. Push Notification Ads** — promotional messages via the app's notification system (promos, retargeting, reminders — e.g. a lunch-time offer ping).

**6. Rich Media Ads** — interactive/multi-element formats (video + interactivity + 360°). Example: IKEA's AR furniture-visualization experience *(real, verified example — IKEA Place)*.

**7. In-App Ads** — describes *placement*, not creative format; an in-app ad can be a banner, video, native, rewarded, or rich-media unit. "In-app" and "banner/video" aren't competing categories.

**8. Cross-Promotional Ads** — one app/product in an ecosystem promotes another (e.g. Nykaa Beauty → Nykaa Fashion). Works best with overlapping audiences.

**9. Native Ads** *(added for completeness — not explained in the source notes, but referenced in the summary table)*: ads designed to match the look, feel, and function of the platform/content they appear in (e.g. a sponsored post styled like an organic feed post) — blends in rather than interrupting, generally improving engagement vs. traditional display/banner formats. *(Fact-check: definition confirmed against standard ad-industry sources.)*

## 10. Consumer Attention & the 6-Second Challenge
Consumers face constant distraction (social, news, apps, notifications, email, video, ads) — marketers must capture attention fast.
**6-second video:** can't do what a 30-second video does — objective is simply **curiosity + attention** (show brand, introduce product, prompt "learn more").

## 11. Consumer Intent
Same ad performs differently by product category, mindset, platform, situation, intent level.
Example: an irrelevant ad interrupting someone's YouTube learning session feels irritating.
**Lesson:** know your audience — otherwise the message becomes generic.

## 12. Brand Integration
Brands embed into entertainment content (movies, web series, YouTube) — works because the brand is remembered *within* content the consumer already cares about. Relevance to audience/content is key.

## 13. In-App Advertising Strategy
Combine formats (banner, video, native, rewarded, rich media) based on objective — **Visibility + Engagement**.
Example: subtle branded elements inside a food-delivery order-tracking screen — visibility without feeling like a traditional ad.

## 14. Cross-Promotion Strategy
Use one product's existing user base to grow another within the same ecosystem (push, SMS, email, loyalty programme, exclusive benefits, in-app promotion).

## 15. Class Activity — Scenario Recommendations
| Scenario | Recommended Formats | Why |
|---|---|---|
| New smartphone launch | Video, Rich Media, Interstitial | Needs awareness + demonstration + high visibility |
| Mobile game wants new users | Playable, Interstitial | Try-before-download + strong visibility for acquisition |
| Car brand — new SUV features | Rich Media, Video, In-App, Banner, 360° | Multiple features benefit from visualisation/interactivity |

## 16. Key Takeaways
1. Multiple formats, each with a different role
2. Format should match the objective
3. Video = awareness/storytelling
4. Playable/Rewarded = high engagement
5. Rich Media = interaction + brand experience
6. In-App = placement; banner/video/native = creative format
7. Cross-promotion grows other products in the same ecosystem
8. Relevant ads > generic interruptions (intent matters)
9. Short-form ads must grab attention fast
10. Know the audience before deciding creative/format/message
